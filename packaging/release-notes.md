**PDF zu Markdown** von Micky Wenngatz: PDF, Word, PowerPoint und Excel per Drag & Drop in Markdown umwandeln. Ohne Python, ohne Terminal, ohne Cloud.

### Welche Datei brauche ich?

| Computer | Datei |
|---|---|
| Mac mit Apple-Chip (M1, M2, M3, M4 …) | `PDF-zu-Markdown-…-macos-arm64.dmg` |
| Mac mit Intel-Prozessor | `PDF-zu-Markdown-…-macos-x86_64.dmg` |
| Windows 11 (64 Bit) | `PDF-zu-Markdown-windows-x64.zip` |

Unsicher beim Mac? Apple-Menü  → **Über diesen Mac**: Steht dort „Chip“, nimm `arm64`, steht dort „Prozessor“, nimm `x86_64`.

### Wichtig beim ersten Öffnen

Mac und Windows zeigen beim ersten Start eine **Warnung**, weil die App nicht kostenpflichtig bei Apple bzw. Microsoft registriert ist. Das ist normal und kein Virenfund. Wie du die Warnung einmalig bestätigst, steht Schritt für Schritt in der **[Anleitung](https://github.com/MiWenn/markitdown-konverter/blob/main/ANLEITUNG.md)**.

Kurzfassung:
- **Mac:** App öffnen → „Fertig“ → Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“
- **Windows:** ZIP entpacken → `.exe` öffnen → „Weitere Informationen“ → „Trotzdem ausführen“

### Was die App kann

- Dateien und ganze Ordner ins Fenster ziehen
- Bilder werden als eigene Dateien gespeichert und im Markdown verlinkt
- Gescannte PDFs werden mit der Texterkennung von macOS gelesen (nur Mac)
- Profile für schlichtes Markdown, Notiz-Apps wie Obsidian sowie KI & Recherche (mit Seitenangaben)
- Kopf- und Fußzeilen in PDFs werden entfernt
- Alles läuft offline auf deinem Computer
